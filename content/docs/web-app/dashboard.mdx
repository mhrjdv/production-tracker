# Dashboard

The dashboard is your home base in Laserman, providing quick access to all your projects and the ability to create new ones.

## Overview

When you first log in to Laserman, you'll see the dashboard with a grid of project cards. Each card displays key information about a project and provides quick navigation to its details.

## Project Cards

Each project card shows:

- **Cover Image** - Custom project artwork or a default placeholder
- **Title** - Project name
- **Genre** - Primary genre classification (e.g., Sci-Fi, Drama, Comedy)
- **Scene Count** - Total number of scenes in the project
- **Last Updated** - Timestamp of the most recent activity
- **Status Indicator** - Visual badge showing project status

### Card Actions

Hover over a project card to reveal quick actions:

- **Open Project** - Click anywhere on the card to enter the project detail view
- **Quick Menu** - Access settings, duplicate, archive, or delete options
- **Star/Favorite** - Mark important projects for priority display

## Creating a New Project

### Quick Create

1. Click the "New Project" button in the top-right corner
2. Enter a project title
3. Optionally select a genre
4. Click "Create Project"

The project is created immediately with default settings. You can add a script and configure details later.

### Import from Script

1. Click "New Project" and select "Import from Script"
2. Upload a script file (TXT, PDF, or FDX format) or paste script text
3. Laserman automatically parses scenes and characters
4. Review the parsed content
5. Confirm to create the project with pre-populated data

> Importing a script saves significant setup time. Laserman's parser identifies scene headings, action lines, and character names automatically.

## Search and Filtering

### Search Bar

The search bar at the top of the dashboard filters projects in real-time:

- Search by project title
- Search by genre
- Search by team member name
- Results update as you type

### Filter Options

Use the filter dropdown to narrow your project list:

- **All Projects** - Show everything
- **Active** - Projects with recent activity
- **Archived** - Completed or inactive projects
- **My Projects** - Projects you own
- **Shared with Me** - Projects where you're a collaborator

### Sort Options

Change the sort order using the sort dropdown:

- **Last Updated** (default) - Most recently modified first
- **Title** - Alphabetical order
- **Created Date** - Newest projects first
- **Scene Count** - Projects with most scenes first

## Project Organization

### Favorites

Star important projects to pin them to the top of your dashboard. Favorites appear in a dedicated section above the main project grid.

### Archiving

Archive completed projects to keep your dashboard clean without deleting data:

1. Open the project's quick menu
2. Select "Archive Project"
3. Confirm the action

Archived projects can be restored at any time from the "Archived" filter view.

## Dashboard Settings

Access dashboard preferences from your user menu:

- **Card Size** - Choose between compact, normal, or large cards
- **Grid Columns** - Set the number of columns (auto, 2, 3, or 4)
- **Default View** - Set your preferred starting filter
- **Show Scene Previews** - Display thumbnails from scenes on project cards

## Keyboard Shortcuts

Navigate the dashboard efficiently with keyboard shortcuts:

- **N** - Create new project
- **/** or **Cmd+K** - Focus search bar / open command palette
- **Arrow Keys** - Navigate between project cards
- **Enter** - Open selected project
- **Esc** - Clear search or close menus

> Use the command palette (Cmd+K) to jump directly to any project without navigating through the dashboard first.
