# Web App Guide

The Lazer web application is your central hub for orchestrating AI-assisted film production. It provides a comprehensive interface for managing projects, scenes, shots, assets, and the complete production workflow.

## Overview

Lazer is an orchestration and traceability layer for AI film production. Unlike generation platforms, Lazer helps you manage the entire workflow: draft, generate elsewhere, capture, compare, select, approve, and assemble.

**Tagline:** "Generate anywhere, decide here, ship with traceability."

## Key Concepts

### Object Hierarchy

Lazer follows a clear hierarchical structure:

- **Project** - Your film or video project
- **Script** - The screenplay or script document
- **Scene** - Individual scenes from your script
- **Shot** - Specific camera shots within a scene
- **Asset Version** - Generated media files (images, videos, audio)
- **Prompt Package** - The prompts and parameters used to generate assets

### Status Workflow

Assets progress through a defined workflow:

1. **Draft** - Initial concept or prompt
2. **Generated** - Media has been created
3. **Needs Review** - Awaiting feedback
4. **Reviewed** - Has been evaluated
5. **Approved** - Accepted for use
6. **Selected** - Chosen as the winner
7. **Final** - Ready for delivery

## Core Features

### [Dashboard](/docs/web-app/dashboard)

Your starting point with project cards, quick access to recent work, and project creation.

### [Projects](/docs/web-app/projects)

Project management including settings, team collaboration, genre classification, and cover images.

### [Scenes](/docs/web-app/scenes)

Scene-level organization with script integration, production view, and five specialized tabs.

### [Shots](/docs/web-app/shots)

Shot breakdown with standardized shot codes, camera angles, framing, and movement specifications.

### [Asset Management](/docs/web-app/assets)

Version control for generated media with filtering, metadata tracking, and winner selection.

### [Compare View](/docs/web-app/compare)

Side-by-side comparison interface for evaluating multiple asset versions.

### [Timeline](/docs/web-app/timeline)

Assembly timeline with dedicated lanes for each asset type to visualize your final edit.

### [Characters](/docs/web-app/characters)

Character profile management with design philosophy, visual cues, and reference portraits.

### [Command Palette](/docs/web-app/command-palette)

Quick navigation and search across your entire project using keyboard shortcuts.

## Getting Started

1. Create a new project from the dashboard
2. Upload or paste your script
3. Review automatically parsed scenes
4. Define shots for each scene
5. Generate assets on external platforms
6. Capture assets using the Chrome extension
7. Compare versions and select winners
8. Assemble your final timeline

> The web app focuses on orchestration and decision-making. Actual media generation happens on platforms like Sora, Veo, or Freepik, then captured back into Lazer for management.

## Navigation

Use the main navigation sidebar to move between project areas. The command palette (Cmd+K on macOS, Ctrl+K on Windows/Linux) provides instant access to any project, scene, or shot.
